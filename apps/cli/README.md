# CLI entry

`apps/cli/src/index.ts` selects launch modes. The root `src/index.ts` remains a compatibility bridge; `whyj` and `bun run dev` keep the terminal entry. Command parsing and behavior still use the single registry in `src/cli`; domain commands are not reimplemented here. Startup regressions live in `test/`, build and copied-package probes in `dev/`.

`whyj web` connects to an authenticated workspace Host before opening its loopback URL. `--no-open` prints the connection without a browser. `--json` emits a stable result without connection capabilities. A missing browser handler leaves the Host available and reports the manual URL; startup failures exit 1. Help, version and one-shot help do not load the terminal or bootstrap the Host.

The Node package contains a separate Host bundle, the Windows launch broker and built React assets. Web mode starts the child with the current CLI executable; installed Node users do not need Bun. `WHYJ_BUN_EXECUTABLE` remains an explicit runtime override. The Node HTTP adapter and Bun listener share authentication, routes and execution services. `bun run build` requires the locked root and `apps/web` dependencies. `bun run cli:smoke` exercises copied package files outside the checkout with no runtime on PATH, concurrent Node launch, Bun source reuse, startup failure and explicit shutdown. It also runs the real bundled Quant/Pi path against a local synthetic model, checks references, skills and terminal capability, then verifies restricted browser continuation in the same context. Body limits, streaming detach and ownership cleanup are included. `WHYJ_NODE_EXECUTABLE` can select a Node version for this development probe; it is not a product setting. The probe does not establish live-provider quality.

The current #76 candidate connects the default terminal to the Host before rendering. AppRuntime's shared mode owns a view and local panels; it does not create an Agent or extensions. Plain text, skills, compact/resume, clear, MCP configuration and extension management use the shared service. Resource mutations require all Host sessions to be idle. Skill and reference suggestions use the Host; command output survives context refresh without entering research history. Active input uses the original run's queue. Report recovery and HUD projections also use the Host's session and execution identity. Shutdown detaches, while explicit interrupt targets the pending command or selected run. The original local runtime remains for standalone use and regression coverage. Unsupported shared commands never fall back to another local Agent. `bun run dev:web` coordinates Vite with the shared Host; `bun run dev:desktop` builds and opens the shared Desktop entry. Its launcher requests normal Desktop quit on Ctrl+C. Full migration acceptance remains unfinished. See the [Host contract](../../docs/agent-runtime/host.md) and [architecture](../../docs/agent-runtime/architecture.md).
