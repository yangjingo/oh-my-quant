# 编辑与证据说明

更新：2026-10-22。系列面向技术负责人，讨论 oh-my-quant 的产品判断、架构、体验与演进成本。01–07 初稿为 2026-10-12，08–12 初稿为 2026-10-13；当前共十一篇中文文章、十一张本地 SVG。

## 内容归属

Docs 实际分为 `agent-runtime/` 和 `quant-harness/`：前者维护通用机制，后者维护完整量化应用，包含数据、计算、执行和 UI/UX。两者的责任不能简化成“会话”与“任务守卫”两个源文件。Docs 维护现行规则与操作；PRD 维护产品形态与核心价值；Blog 解释真实问题、错误判断、修正、代价和仍未解决的部分。旧设计、历史汇编与独立决策账已删除，不另设归档索引或旧路径跳转页。删除的理由和损失直接写入[第七篇](./07-artifacts-and-boundaries.md#documentation)，这里不再保存历次整理流水。

本文和博客描述的是工作区，不是 HEAD、发布包或线上部署。当前接口仍以对应设计文档为准，不能从一段历史叙述推出产品完成度。

## 叙事与图文

每篇采用四个正文部分：提出一个问题，展示原判断遭遇的冲突，解释新机制，回到结果、成本与重审条件。这是 QCSR 的内部结构，不把框架标签写进标题。

ABT 用于推进因果：承认原方案的合理性，但用实际限制打破假设，因此引出有代价的选择。不要机械重复连接词，不虚构事故、团队动机、会议决定或效果数字。结果可以是一个被明确界定的缺口，不必包装成成功。

每篇的 SVG 表达需要图解的所有权、状态、流程或布局；保留替代文字、图注和边界。它们不是终端实拍、性能测量或供应商素材。产品颜色规则以 [DESIGN](../../DESIGN.md) 为源，不在正文里创建第二套主题规范。

## 如何处理被推翻的判断

| 主题 | 正文中的反例与修正 | 不能推导的结论 |
|---|---|---|
| 01 · 架构 | 缩短文件不等于可替换；接入内核不等于迁移完成 | 全部模块独立发布或所有入口事务化 |
| 02 · 数据 | 保存、单源能力、研究成功分别定义 | 用户账号权限已恢复 |
| 03 · 上下文 | 最近操作挤掉任务证据；零模型压缩说明过时 | 恢复材料就保证解释正确 |
| 04 · 能力 | 包元数据不能替代导入；统一任务模板误伤材料解释；检查器误拒合法读取 | 所有 Skill ready 或已形成安全沙箱 |
| 05 · 评测 | 绿测之外仍有账本、RSI 暖机/递推、贡献排名与情景算术错误 | 已得到总体正确率或完整语义验收 |
| 06 · 终端 | 旧报价与新时间混合；取消不等于停止发布 | 回调耗时等于用户看到画面的时间 |
| 07 · 文档与制品 | 相同 GOALS 被误读为新增需求；只删归档仍留下分散规范和冲突 | 本次整理保留逐字历史或降低 Agent 错误率 |
| 08 · 产品 | 局部功能成功不等于研究闭环 | 固定任务完成证明新用户可以独立完成 |
| 10 · 视觉 | 重复扣高与截断；旧色表分叉；独立文本渲染子系统超出当时需求 | 行数增加等于效率提升或无障碍验收完成；这不否定后续 Desktop GUI 计划 |
| 11 · 发现 | Help 截断，查询曾误执行动作 | 十条命令就是最优设计 |
| 12 · 恢复 | 长诊断不可达，滚动修复又抢占编辑键位 | 所有错误自动修复，取消撤销已保存设置 |

历史例子保留其日期、输入和失败含义；无需把旧测试数量、全部日志与外部生态目录搬进博客。只有明确的实现或回执支持时才称“已修正”；离线重检与新模型复跑分别描述，保留旧结果，不改成理想答案。

代码链接定位机制，测试链接定位可重复检查，两者不代替真实执行证据。少量链接指向本机 `output/` 原始回执；这些文件不保证随仓库克隆存在，也不在网站发布白名单内。正文必须自足地说明反例，不让读者依赖私有输出才能理解论点。网站构建需要区分可公开链接与仓库内证据，不直接发布整份运行材料。

第 02 篇关于面板、状态栏与 `daily_basic` 的开场来自用户反馈，不是本轮再次请求账户所得。权限不足可以与配置传播问题同时存在，不能仅凭错误句子认定唯一根因。

## 构建与复核

Markdown 和 SVG 是编辑源；[build.ts](./build.ts)生成[离线 HTML](./index.html)，不单独编辑生成页。[check.ts](./check.ts)检查全量目录覆盖、本地链接与锚点、十一篇结构、SVG 说明及离线资源。结构检查不判断推理质量，另用独立读者检查因果、证据范围和遗漏。

~~~powershell
bun run docs/blog/build.ts
bun run docs/blog/check.ts
~~~

本轮为文档整理，没有重新运行模型、行情、账户或全量产品测试；不把先前浏览器、终端和真实服务的结果记作本轮验收。
