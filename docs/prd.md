# WhyJ Quant 产品定义（PRD）

WhyJ Quant 是面向个人投资者与专业量化用户的长期研究工作台。围绕持仓和关注标的，把丰富的数据与因子、持续观察、组合比较和专业报告连接起来，并向外部工具与生态开放。以下定义产品方向，不作为功能交付清单。

<a id="scope"></a>

## 产品形态

- **Desktop**：面向 Windows/macOS 用户，提供直观、完整的桌面研究体验。
- **CLI/TUI**：面向 Linux 专业用户，延续已有终端基础，支持专业研究与自动化工作流。

两种形态共享 Quant 能力。Web 是共享界面和浏览器访问入口，不单独作为第三种产品。

<a id="features"></a>
<a id="requirements"></a>

## 核心功能与特色

1. **内置丰富的 Quant 数据源**：覆盖行情、基本面、宏观、新闻等研究材料，减少用户寻找数据和接入服务的成本。
2. **丰富的因子库与自适应观察指标**：提供常用量化因子和观察指标，围绕标的、持仓、研究目标与市场变化自动调整观察重点，并允许用户自行选择和调整。
3. **持仓 Portfolio 的长期追踪与比较**：持续记录持仓、权重、收益和风险的变化，支持不同组合、基准与时间区间的比较，帮助复盘投资决策。
4. **长期追盘与持续观察**：围绕关注标的和研究假设持续跟踪行情、事件与指标变化，积累连续的观察记录，帮助用户识别值得重新研究的变化。
5. **精美、专业的报告产出**：将研究过程与结论整理成结构清晰、图表精美、来源可查的报告，支持日常复盘、阶段总结和分享。
6. **开放的系统与生态**：开放模型、数据源、因子、Skills、MCP 与工具的接入和扩展，让用户复用已有能力，也能加入自己的研究方法与工作流。
