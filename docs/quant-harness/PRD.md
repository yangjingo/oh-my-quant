## 1. 产品目标与用户

WhyJ Quant 是面向个人量化研究者的交互终端。用户围绕自定义标的组合，完成“配置 → 获取数据 → 分析与比较 → 形成报告 → 恢复研究”。开发者能够按模块增加数据、计算与研究能力。产品价值应来自数据可解释、计算可核验、研究可延续和扩展成本可控。

主要场景：首次配置模型与行情；每日查看 A/HK/US 股票、指数和基金；维护观察组合并比较风险收益；执行因子与策略研究；将分析导出为可追溯报告；继续上次研究。实盘执行是明确的后续目标，需要独立执行契约。

“Portfolio”当前指用户维护的标的与分组，不包含券商账户、实际数量、成本或现金余额。公开基金披露的成分股也不等于用户个人持仓。任何个人资产接入都不得通过猜测现有本地文件补齐。
