# 年度报告：让长期观察保留当时的依据

年度报告容易在两种方向上失真：一是把今天的数据和解释重新拼成“当时已经知道”的故事，二是把观察组合的假设收益写成用户实际账户的业绩。报告越完整、视觉越专业，这种混淆越不容易被注意。

这里的设计目标是保留一份可回看的研究判断：研究了什么范围，使用哪些输入，采用什么比较方法，当时记录了哪些选择，以及这些材料不能证明什么。报告负责组织证据，不负责制造年度完整性。

## 先确定报告对象，再谈年度叙事

默认年报围绕固定的观察组合比较生成。生成服务接收明确年度、截止日、比较版本和可选研究决策，交付带来源与限制的独立报告。它不读取用户账户，不修改观察组合，也不把短期比较自动扩充成全年记录。

年度必须从年初覆盖到指定截止日；年末以前应称为年内截至日，而不是完整年度。请求区间与实际共同估值日期分别展示，因为休市、数据缺失与汇率缺项可能缩短可计算范围。首个可用估值日之前的收益不能自动计入。

当前 CLI 研究不开放新的跨组合比较，年报依赖的比较需来自已有记录或显式宿主服务。历史服务仍然可核验，不意味着所有当前入口都能重新发起同一流程。

## 计算层提供事实，报告层组织解释

报告不接受模型直接填写收益数字。生成时先核对原比较、对应数据与方法，再重算结果，最后形成图表和文字。这样，报告样式调整不会悄悄改变收益算法，模型叙述也不能替代计算依据。

正文应让读者看懂范围、收益与风险、覆盖缺口、来源和假设之间的关系。价格口径、报价币种、共同日期及权重方法需要与结果一起出现；缺失指标保持不可计算，不能为了表格整齐填成零。

这套安排仍有边界：重算一致只证明报告忠实于给定输入，不能认证币种假设、供应商历史可得性或公司行动处理。收益领先基准的百分点差不是风险调整 alpha；稀疏估值点上的低回撤也不能证明全年风险低。具体方法由[组合比较](./portfolio-comparison.md)维护，年报不复制另一套规则。

## 研究决策需要记录，不能从结果倒推

静态组合只表明某个版本选择了什么标的，不能说明年内何时决定加减仓，更不能证明真的成交。因此，研究决策作为独立输入，记录明确的选择、理由、引用比较、声明日期和实际记录时间。

声明日期与记录时间必须并存。事后补录的判断仍有回顾价值，但不能因此变成当时已经留下的决策证据。引用材料晚于声明日期时，同样应让读者看见，而不是把时间差抹平。

报告可以接受明确选中的决策，也可以在用户显式选择后纳入当时本地匹配的记录。后者仍不是“全年所有真实决策”：未记录的判断不可发现，理由真实性不可认证，超出可处理范围时也不能静默截断。生成后冻结选择，后续补录不改变旧年报。

这种方式增加了明确选择的成本，却减少了事后叙事把所有结果解释成先见之明的空间。日志的用途是支持反思，不是给判断或交易盖章。

## 历史观点是阅读背景，不替本次研究背书

报告目前使用固定版本的历史观点，保留作者、原文、发表时间与原始语境，不让模型临时补造参考文献。Buffett 关于低成本指数化的讨论来自特定信托安排的语境；Marks 讨论的是在无法预测转折时如何认识所处位置。它们可以帮助提出问题，不能直接推出本报告应采用的配置。[1][2]

历史观点不能因为出现在当年的报告里就被写成当年新观点；晚于报告截止日发表的材料也不能当作此前已知信息。本项目的解释应与作者原意分开。当前目录有限，不宣称已完成多作者、相反观点或年度研究材料的全面综合。

## 为什么要固定报告版本

年报生成后保存原始输入绑定与 HTML 版本。恢复核对已引用的比较、数据和决策，重新交付保存的页面，不以当前模板或最新行情改画过去。来源缺失或损坏时，应说明无法核验，而不是把新数据补成旧证据。

固定页面与持续改进之间确实存在张力：旧报告可能保留旧措辞，新的解释规则则应进入当前阅读提示或新版本。保留旧字节使研究历史不会随产品升级悄悄变化，也要求读者区分原记录和后来的修正。

完整年报仍可能包含组合名称、研究配置与理由，不因没有账户金额就自动成为公开文件。它与[报告分享](./artifacts-design.md)的白名单副本承担不同职责。

## 私有账户输出是另一条边界

真实账户年报必须经可信宿主显式提供完整历史，或由用户选择规范化历史文件。读取权限、来源转换与历史完整性由账户接入方负责，计算层按[账户业绩](./performance.md)检查权益、出入金和费用；不能从执行模块的一张当前快照推算全年收益。

私有账户值与假设组合曲线分别呈现，不能拼成一个“组合表现”。当前年度边界严格采用 UTC，券商本地年度仍需明确转换。规范化文件能够参与计算，不表示任意原始账单已被正确解析，也不表示真实券商连接已经接通。

可信宿主可以在内存取得私有 HTML；显式文件导出写到用户选择的新位置，不进入默认研究报告存储、模型上下文或公共分享。终端入口提供选择与确认，但不新增账户真实性认证。当前界面和合成样本支持这条隔离路径，真实账单和服务仍待独立核对。

报告的完成条件因此不是“页面生成成功”，而是其范围、输入、方法与可见性相互一致。它应该帮助读者知道下一步需要补什么证据，而不是以完整外观掩盖未完成的研究。
