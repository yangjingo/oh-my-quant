# 共享 Web UI：展示、客户端与服务边界

`apps/web` 是供浏览器与 Desktop renderer 复用的 React + TypeScript + Vite 模块。它承接 #84 的终端式布局，并复用 [PR #81](https://github.com/yangjingo/oh-my-quant/pull/81) 的包基础与订阅/取消契约。原来的 `prototypes/web-terminal` 已撤除，不再维护第二套 HTML 字符串渲染器。

本页说明已实现的模块边界。[架构](../agent-runtime/architecture.md)定义 Host、服务、runtime 与 storage 的职责；[UI/UX](./uiux.md)和 [DESIGN](../../DESIGN.md)维护交互与视觉原则。初步本机 HTTP/SSE Host 已连接真实 Agent；桌面加载与跨入口接续仍需分别集成验收，不能以浏览器演示代替。

## 代码按职责组织

| 位置 | 责任 | 不承担的责任 |
| --- | --- | --- |
| `src/main.tsx`、`mount.tsx` | 选择客户端并挂载共享 Workbench | 不创建 Agent 或读凭证 |
| `src/components/` | 对话、行情、输入、全局设置与独立研究成果面板 | 不调用 provider、storage 或业务服务 |
| `src/state/workbench-store.ts` | 读取客户端快照、订阅事件、选择会话和呈现错误 | 不作为运行或持久化真值 |
| `src/client/contract.ts` | 带 workspace/session/run 身份的 UI 端口 | 不是已发布的 HTTP 协议 |
| `src/client/disconnected.ts` | 明确拒绝没有 Host 的操作 | 不回退为虚构成功 |
| `src/features/composer/` | 纯文本触发范围与候选替换 | 不遍历本地文件或解析研究证据 |
| `src/styles/`、`public/assets/` | 共享主题、局部样式、品牌与许可字体/图标 | 不存放 PR 验收截图 |
| `dev/`、`test/` | 显式演示适配器、验证入口与契约回归 | 不进入正常生产数据路径 |

组件通过 `WorkbenchClient` 读取会话、行情、证据、成果及偏好，并提交、取消或订阅。`mountWorkbench(element, client)` 是集成入口。实际服务实现属于 `src/app`；依赖组装属于 `src/runtime`；文件与 journal 属于 storage。renderer 不通过相对导入绕过这些边界。

旧单股工作台的复核和删除协调已提取至 `src/app/services/research-workspace.ts`，HTTP 路由调用同一服务。删除先读取并校验元数据，再删除研究并以原 revision 提交关联变更；结果返回完整的最新元数据，让直接调用和浏览器都保留其他客户端新增的项目。损坏元数据仍阻止删除，陈旧写入仍被拒绝。该提取不改变旧保存格式，也不表示通用 Quant 会话已具备完整的共享服务契约。

旧单股界面的显式继续会跟随返回的新 runId，并在对话中保留上一轮取消/失败状态。新运行仍属于原 conversationId，复用已有证据；对旧 run 的停止请求不会停止新运行。原有 50 次研究和 12 轮历史上限继续生效。

独立 Vite/preview 入口使用未连接适配器并禁用提交；`web:start` 构建后由本机 Host 提供静态页面，入口标记选择真实客户端。只有显式 `demo` 模式加载 `dev/demo-client.ts`；生产构建检查拒绝示例运行和会话标记。演示模式明确标注合成行情、证据及报告；其偏好可存入独立浏览器键，模拟会话只在内存中。

## 初步本机 Agent 连接（#101）

`src/app/services/research.ts` 通过现有 `createQuantResearchAgent` 与 runtime 依赖组装复用 Pi 会话、工具和 journal；`src/app/workbench` 提供 HTTP/SSE 适配，不新增执行循环。初始连接排除 shell、外部 skills 和动态工具配置。共享 DTO 归 `src/types/workbench.ts`，Web 只通过 `client/host.ts` 的 HTTP RPC 与 fetch SSE 交互。Host 仅监听 127.0.0.1，校验 Host/Origin、内存 capability token 和严格参数；token 不写 URL，模型凭证不发给 renderer。工作区锁限制单一写入者，但不提供 Host 发现和跨入口接续。

同一会话追问复用 Agent 上下文。SSE 提供带单调 revision 的全量快照，合并短时间内的更新；重连重新同步，拒绝旧 revision 和取消运行的迟到事件。断开只释放订阅；停止按钮/Ctrl+G 显式定位运行并中止请求。请求结果未知时不自动重发提交，以免重复工作。模型连接失败保留已显示内容并提示错误类别，不暴露 provider 原始响应。

服务明确请求澄清时显示“等待补充信息”，保留问题并停止本轮计时。输入框的回答以 `followup` 携带问题所属 run 和修订发送，创建新轮次；页面刷新不自动回答，旧轮次迟到事件不能恢复运行。重命名成功后重新读取会话修订，后续提交使用最新值。

提交携带 `requestId` 与已读取快照的 `expectedRevision`；直接调用和 HTTP 共用运行时校验。相同 Host 内同一请求返回原接受结果，不再创建 Agent；相同 ID 改变输入或陈旧修订会被拒绝。此回执只在内存中，不能作为 Host 重启后的自动重放依据。取消携带完整 workspace/session/run 身份，不允许只凭 runId 改变其他会话。服务关闭后，仍在等待就绪的提交与新建会话也会被拒绝。

服务端口还提供显式 continue/followup、固定版本 save/reload、分叉 review 与修订检查后的 deleteSession。继续和追问创建新 run，报告重开只读取，复核另开会话；当前页面尚未增加对应操作按钮。完整身份、损坏保护、终态 journal 位置及失败边界见[无界面研究服务](../agent-runtime/services.md)。

设置可修改当前 provider 的模型 ID 和支持的 thinking level，使用存储 revision 拒绝覆盖其他修改；运行时拒绝改模型。已配置凭证不等于已验证连接，新增 provider/key 仍通过本机配置。默认保留当前推理深度。回答上方持续显示动态状态与累计用时：等待模型响应、思考中、调用工具、正在生成回答；仅收到真实 thinking 事件才标为思考中。思考过程默认收起，展开后流式显示模型实际返回的可显示文本；模型未返回文本时只保留真实阶段提示，不生成替代内容。工具执行时直接显示工具名称，展开可看历史与耗时。计时在完成、失败或停止时冻结；减少动态效果设置禁用旋转动画。计时只表示等待时长，不表示完成比例。示例只填入假设数据草稿，用户确认发送后才调用模型。

数据源页通过 `researchSource` 修改现有研究工具的默认路由，列出 AKShare、Tushare、LLMQuant 与 Financial Datasets；只投影是否需要/已配置凭据，不发送密钥。保存复用设置 revision，拒绝无适配器的名称与运行中的修改。AKShare 仍需可导入依赖的 Python（可通过 Host 启动环境 `WHYJ_PYTHON` 指定）；公开接口不等于实时可用。工具保留字段级回退及实际来源，界面不承诺所有市场或字段都可取得。`source` 保留为旧的概览连接偏好字段，不用它表示取数成功；底栏显示“研究源”而不是暗示已通过联网验证。adata、stock-api 尚未接入项目适配器，skill 中的获取规则不会自动注册新工具。

思考文本与最终回答分别保存和展示。Host 只提取非 redacted 的 thinking 字符串，不把签名、隐藏块或原始 provider payload 发给页面；已知凭证与跨流式片段的凭证前缀会被遮蔽。文本以纯文本渲染，长内容在过程区内滚动；阅读较早内容时暂停跟随，原生 details 支持键盘开合，增量更新不重置展开选择。停止或意外中断保留已收到的部分，复制回答只复制最终回答。新记录通过原检查点保存安全投影，旧记录缺少此字段时照常读取，不自动从原始 journal 补取历史思考。

折叠的思考行在实际思考阶段显示最新非空行，并随真实文本更新跟随行尾，不使用独立跑马灯；阶段结束后隐藏行内文本摘要，只保留状态；完整过程仍可展开查看。展开后隐藏行内摘要，过程正文保留阅读位置控制。运行中的工具直接呈现紧凑动作行，附有限输入摘要和状态；详情保留工具身份与调用标识，结束后汇入可展开的执行记录。无工具时不生成空的运行详情。普通完成回复不重复显示结束状态，失败、停止和中断仍保留明确提示。消息时间按浏览器本地时区显示月日与时分，悬停和 time 元素保留原始时间。正文居中限宽，三列及以下表格优先折行，四列及以上保留局部键盘滚动。只改变视图，不改执行、持久化或核验含义。

本阶段文件引用仍未开放；只有显式保存成功才返回报告版本，普通回答完成不会自动变成核验归档。工具文本取证记录见下文。会话投影保存在独立的私有检查点中，Host 重启后恢复列表；新问题按需打开原 Quant journal，不自动重放原任务。浏览器按工作区/会话保存选择与未发送草稿，存储不可用时明确提示。意外中断的工具结果标为待核对，显式确认只解除提问限制。格式与失败边界见[会话连续性](./workbench-sessions.md)。#75 的发现/生命周期与 #77 的完整执行恢复仍是后续工作。启动和私有配置目录选择见 [README](../../apps/web/README.md)。

执行记录按同一调用标识合并“准备中 → 执行中 → 返回结果”，准备参数不等于已执行；准备阶段被取消时记为“未执行”。可读动作标题来自现有工具注册表的展示元数据，原有终端标签不变。Host 对调用输入只提供经过校验、限长的摘要，不转发完整参数、查询或文件路径；实际工具返回的文本经脱敏和限长后保存在会话检查点，执行详情与证据页可查看，详见下文。每轮默认汇总状态与数量，运行时展开执行记录；单条记录按需展开工具身份与调用标识。失败、停止、未执行分别呈现，工具返回不代表结论已独立核验。设计借鉴 [DSH 的同一调用三阶段](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/.agents/notes/implemented/architecture/2026-09-22-tool-call-three-phases.md)和 [Codex 的执行条目生命周期](https://openai.com/index/unlocking-the-codex-harness/)，继续复用现有 Agent 及事件流。

## 会话状态与运行生命周期

提交已被服务接受后，客户端重新读取权威会话摘要，更新自动命名和运行次数；无需刷新页面即可在标题、侧栏和名称搜索中看到新名称。列表刷新失败不把已接受的问题变成提交失败，也不自动重发；较晚返回的列表不能覆盖期间发生的会话选择或重新加载。

CI 浏览器证据在纯前端演示之外，通过 `tests/app/dev/review-host-fixture.ts` 启动临时目录中的真实 Host、Pi 会话和计算工具，使用本机受控的假模型响应停留在各执行阶段。`dev/review-host-evidence.mjs` 验证自动命名、刷新不重放、模型保存与忙时拒绝、停止保留草稿、失败和未执行记录、终态计时冻结及减少动画偏好，并录制截图和录像。该夹具不读取个人设置、不连接付费模型；停留时间不能作为真实性能数据，静态 Vercel 演示也不能替代 Host 验收。

草稿、当前会话、面板开关、字号与滚动位置属于视图。运行身份、状态、对话和成果来自客户端。切换会话或卸载界面只释放观察者；取消必须是显式操作，并传递准确 runId。

状态投影用选择代次拒绝旧会话读取覆盖新选择；快照读取期间收到事件时重新同步。事件按会话身份分流，取消后的同一运行不被迟到更新复活。提交失败保留草稿并显示错误；提交期间编辑或切换会话也不清除其他草稿。Host 启动订阅只发送 ready 握手，客户端按需读取选中会话；已结束 Agent 与观察者释放，旧历史按需读取。开发适配器的计时器不提供持久化保证。

状态事件必须保留所属 runId；不能用 `null` 结束当前运行。投影发现缺少运行标识时保留已有状态并提示重新连接核对。偏好或重命名失败会拒绝调用，让设置面板在原处显示失败；只有客户端确认成功才显示保存成功，连接建立仍是另一项状态。

## 组件与可观察行为

Header 保持图标、版本与模式信息；演示标为“交互演示 · 合成数据”，不会以模型名称暗示真实调用。Sessions 提供搜索、选择与新建；主区保留问题、回答、过程状态、结论和研究成果入口。状态展示采用中文，区分本轮结束、结论记录和独立核验。过程区只呈现客户端提供的执行状态，不伪造模型推理或百分比。

Composer 使用原生 textarea，空输入光标从首行起点开始；真实连接提示研究问题与界面操作；演示入口另标明 @ 示例引用。提示符与发送图标使用金色强调。空闲时 Enter 发送、Shift+Enter 换行，输入法组合期间不发送。运行时 Enter 保留草稿，不取消也不并发提交；停止按钮或 Ctrl+G 才会显式取消当前会话的运行。宽度与字体布局变化会重新计算输入高度；长草稿达到上限后在输入区内滚动。

`/` 菜单提供新建、会话切换、设置、观察组、证据、报告与帮助等界面动作。尚不支持的命令保留草稿并说明原因；这里不是第二套业务命令执行器。`@` 候选由客户端按会话查询，覆盖文件、目录、会话和证据，插入带类别/身份的 token；↑/↓ 选择，Tab/Enter 补全，Esc 收起，替换保留光标之后的文本；延迟光标更新遇到后续编辑或显式选择时不再覆盖用户操作。真实本地文件授权、读取、证据核验及 token 解析属于 Host；演示候选不能证明本机引用已接通。

Overview 只展示客户端提供的行情与分组，缺失值保留为空。明确提示刷新时间不等于交易日期；切换未连接数据源后不继续伪装为已取到行情。Settings 仅提供界面偏好、客户端模型/数据源/观察组偏好、运行状态、会话名称与帮助，失败保留本次输入并在面板内提示。

“研究成果”面板从对话直接打开，分为结论与条件、证据、报告版本。证据保留来源、日期和缺失项；版本仅提供现有端口返回的标题、时间和校验标识，可对照最近两个版本的元数据。元数据不等于正文差异；当前导出是展示快照的 Markdown 摘要，不冒充存储中的不可变报告文件。原始文件、原始报告读取及重新取证仍未接入；工具返回文本与其中已有的计算明细可以查看，面板会说明截断和未核验边界。

回答支持 Markdown 段落、列表、代码和 GFM 表格。渲染禁用原始 HTML、拒绝非 HTTP(S)/片段链接，不自动加载模型文本中的外部图片；宽表格在局部滚动。Markdown 与成果/设置面板按需加载，避免其全部解析代码进入初始壳层。默认正文 15px，必要操作不依赖悬停才可读；沿用共享黑金配色。

Web Host 在 runtime 组装时选择 Markdown 展示策略，系统提示、逐轮提示和 skill 展示提示保持一致；CLI/TUI 默认仍采用终端策略。研究约束、指标含义和工具核验规则继续共用。旧回复若包含独立的终端横线且没有 Markdown 代码围栏，则以可换行的纯文本保留原始空格与行界，避免普通段落折叠列间距；不推断表格列、不修改存储或复制的正文，也不把模型对故障原因的判断视为已验证事实。

宽屏可并列显示会话和概览，跨入窄屏时收起侧区，窄屏侧栏与概览互斥；正文滚动与底部输入分离。空会话提供可编辑的问题建议，点击只填入草稿。弹窗使用原生 dialog、键盘导航与关闭后焦点恢复；成果标签支持左右方向键与 Home/End。桌面加载、系统输入法和屏幕阅读器仍需在目标环境验收。

## 开发与验证

`Web review evidence` 工作流在隔离环境构建明确标注的合成演示和未连接的生产入口，运行现有 `dev/capture.cjs`，保留实际宽窄屏截图、交互录像和版本清单。基线演示使用 PR base，当前截图记录 head 与实际检出的合并候选，不能混称同一修订。产物在 Actions 中保留 30 天，通常需要登录 GitHub 下载；过期后应重新生成。截图不进入源码，CI 不读取个人设置、真实凭据或付费模型；静态预览不能证明真实 Agent、SSE 或桌面行为。

根 `web:dev` 运行正常入口，`web:demo` 运行显式演示；`web:build` 生成正常产物。具体安装、独立 demo 构建和浏览器采集入口见 [apps/web README](../../apps/web/README.md)。只部署构建产物，不上传源码目录、测试或本地凭证。

`web:check` 覆盖 TypeScript、纯编辑逻辑、客户端生命周期、会话隔离、异步选择、失败提交、依赖边界、Vite 生产构建和示例数据排除，已纳入根 `check:release` 与两平台 CI。浏览器验收另覆盖宽/窄屏、正常/空/运行/错误状态、候选键盘操作、会话切换及设置。截图保存到忽略目录或 CI 制品，PR 证据须注明所测版本；旧原型截图不证明当前 React 修订。
