# 组合比较：先建立可比性，再讨论谁表现更好

把两条收益曲线画在一起很容易，说明它们为什么可以比较则困难得多。观察日期、报价币种、权重规则和数据缺口只要有一项不同，排名就可能回答了另一个问题。组合比较首先要建立共同条件，其次才计算结果。

当前 CLI 只研究一个活动观察组合，不开放新的跨组合比较。本页维护独立比较服务与历史结果的设计，支持显式宿主使用和已保存研究的解释；它不是当前 CLI 功能可达性的承诺。观察组合也不包含真实账户的数量、现金或成本。

## 比较请求必须表达哪些选择

比较服务接收两组固定成员与版本、区间、基准、报告币种、报价币种及权重方法，交付共同估值日期、各条曲线、指标、排除项和完整假设。组合编辑是另一项操作；比较不能为了完成计算而修改用户的观察组。

请求开始时固定成员和设置，避免计算过程中另一窗口的编辑改变研究对象。成员名称用于阅读，身份与版本用于绑定。这样的快照会与随后编辑的组合不同，但这正是可复查研究所需要的稳定性。

报价币种必须来自明确输入或已核实资料，不能只由市场推断。跨币种时先换成同一计价单位再比较，否则价格上涨可能被汇率变化抵消。价格不变、汇率从 7 变为 8.4 的简单例子，足以说明本币零收益与基准币 20% 收益可以同时成立。

## 对齐会损失样本，但不对齐会改变含义

当前方法使用成员与基准共同拥有价格及同日汇率的日期。缺项日期从整份比较中移除并说明原因，不前向填充汇率，不把缺价格当成零收益。基准不可用时，比较不能悄悄退化成无基准排名。

这一选择牺牲覆盖率。跨市场休市差异越大，共同日期可能越少，甚至无法计算；但至少各条曲线使用同一段观察。用一个标的两天的变化与另一个标的一天变化直接加权，会把期限差误当成组合差。

当前汇率采用 Frankfurter 的 ECB 来源，是日度参考数据，不是可成交报价。[1] 即使日期相同，各市场收盘也不同时发生，因此共同日期不等于同步交易时点。结果必须保留这个限制，不能把日度对齐夸大成可实际执行的跨市场策略。

缺少成员默认阻止比较。只有显式选择排除，才对符合缺失条件的成员剔除并重新分配剩余权重；来源故障不能被当作合法的缺成员理由吞掉。排除后的结果研究的是新的有效集合，而不是原组合的完整表现。

## 权重规则往往比指标名称更重要

买入持有固定初始份额，权重随相对价格变化；再平衡则在共同估值日恢复目标权重，作用于下一段收益。两者回答不同问题，不应只作为一个隐藏参数。

以初始等权的两只资产为例，一只价格从 100 到 200 再回 100，另一只从 100 到 50 再回 100。买入持有最终回到初值，而每期恢复等权的模拟结果会不同。区别来自中途交易假设，不是计算误差，也不能据此认定现实再平衡必然更好。

当前两种方法均允许碎份额，采用零成本假设，未完整处理交易费用、税、分红和公司行动。再平衡越频繁，这些缺省假设越值得注意。设计上保留方法与假设，而不是输出一个脱离过程的收益数字。

## 更高的比率，不自动意味着更好的策略

累计收益、日历年化收益、波动率、Sharpe 和回撤描述不同方面。共同估值日期之间可能间隔不等，当前风险年化使用观察频率近似；它没有把所有收益先转成相同期限，也未估计统计不确定性或修正序列相关。

Sharpe 原文专门讨论时间依赖，因此跨期间比较不能只看已经年化的显示值。[2] 当前结果使用零无风险率；只有一个收益期间时，风险比率保持不可计算。这里没有人为设置“满多少条就可信”的阈值。

超额收益是两个累计收益率的百分点差，不是风险调整 alpha。观察点之间可能出现更深回撤，低观察回撤也不等于低实际风险。数字可以支持对这份样本的描述，不能单独证明稳定的风险调整优势。

研究输出会明确相对基准的方向，降低模型在表格正确后又写出相反结论的概率。有限回答检查仍可能漏掉复杂改写，不能代替完整语义审阅。

## 保存的是研究条件，不只是最终曲线

每份比较固定成员版本、价格与净值、汇率观察、权重和缺失规则，并保存结果。历史读取根据原输入重算，数据或结果不一致时明确失败，不以当前组合或最新缓存替代。

独立比较能够证明结果与保存输入一致；报告还需核对原请求及公开数据版本，才能把它列入已核验结果。两者的证明范围不同，不能因为历史曲线能打开就认为整条来源链仍然完好。

完整研究可能含组合名称与用户输入。公开分享使用匿名标签和允许的公开标的、比例及比率，不直接复制原档案。这样分享者可以讨论方法与结果，而无需连同研究身份和私人上下文一起交付。
