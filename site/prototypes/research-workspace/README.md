# 投资研究 Agent 工作台交互原型

2026-10-15。临时原型，保留在主仓的 `prototype/research-workspace` 分支，不进入 main 或官网发布。基线为主仓 main `b0b55db`（v1.4.0）。

要验证的问题：在同一个研究任务中，对话、执行过程、证据和复核结果应该怎样组织，才能让用户找到依据并理解判断变化？原型提供三个结构不同的候选布局，等待实际使用反馈后选定或组合。

## 启动和切换

在仓库根目录执行：

```sh
bun run --cwd site prototype:research
```

打开 http://127.0.0.1:4174/prototype/research-workspace/?variant=A 。不用安装依赖、填写密钥或启动现有 CLI。服务器只绑定本机；端口被占用时先关闭已有原型服务。开发服务在 `NODE_ENV=production` 时拒绝启动。

| 参数 | 页面结构 | 主要检验 |
|---|---|---|
| `?variant=A` | 左侧研究历史、中间 Agent 对话、右侧成果 | 提问、执行、审阅能否衔接 |
| `?variant=B` | 窄导航、主要区域为图表与证据、右侧 Agent | 看图和检查计算是否更顺畅 |
| `?variant=C` | 研究笔记正文、内联依据、右侧复核对话 | 保存研究与理解版本变化是否更清楚 |

底部按钮或左右方向键切换，URL 保留选项；输入框、选择框和弹窗中不拦截方向键。同一浏览期间切换布局保留当前演示状态。窄屏通过“研究对话 / 成果与证据”切换，避免挤成三栏。

## 研究任务

“这只股票回调后，原假设是否仍成立？相对大盘和板块如何？什么证据能确认，什么情况会失效？保存研究，下次收盘后复核。”

从 stock-evaluator 提炼的核心是：先分类、多证据判断、已完成日线、观察/触发/确认/失效、明确缺口与条件化判断。首版任务是收盘后单股结构跟踪，不扩展成全市场 Top3、完整买点资格或交易执行。真实 Agent 应选择工具、检查返回结果并补充证据；本原型只检查交互，不实现这些研究能力。

演示使用“标的 A”和自带归一化合成序列，原失效边界为完成日线收盘低于 108，收复参考为 110。它们不是任何真实证券的价格或投资结论。复核增加一个合成末点：111 只触发、尚未确认；107 使原假设失效，原边界保持不变。E1 展示当前版本序列与算式，E2 展示同口径样本和缺口。

## 可操作路径

1. 初始页面打开完成的 T0 示例。点击 E1/E2 查看来源、截止版本、输入和公式。
2. 点击“新建研究 → 运行研究示例”，查看模拟步骤；运行中停止，再继续。
3. 保存到内存，主动复核得到 T1；打开 T0 核对原数据与边界没有被后续结果覆盖。
4. 在“设置与连接”选择“缺少板块证据”，检查已有标的/大盘仍保留，板块显示缺失而非零。
5. 选择“下一次复核破坏原结构”，再主动复核，检查旧假设失效、边界不下移。
6. 用三个布局及窄屏走同一路径，比较问题输入、停止、证据定位和历史打开是否容易发现。

原型限制：运行或暂停期间不切换到历史版本，点击会提示先继续或新建研究，当前步骤与继续入口保留。正式实现再将历史审阅与当前任务状态独立。

输入任意问题只演示固定样例，不进行真实模型分析。保存、历史与复核仅在浏览器内存；刷新清空，不写入配置、账户、文件或浏览器存储。切换演示情形会重置版本。运行计时是预设动画，不是性能基准。

## 实现和发布边界

静态 HTML/CSS/JavaScript，加一个本机 Bun 文件白名单服务器。共享状态由三种渲染视图消费，无第三方运行依赖、网络 API、凭据或外部字体请求。复用 `site/public/fonts`，视觉遵循根目录 [DESIGN](../../../DESIGN.md)。

`site/scripts/build.mjs` 只发布其已有的四个页面与显式 public 资产，不复制本目录；原型入口没有加入官网路由或生产构建。截图属于合成 UI 的浏览器观察，不代表真实模型、行情、账户或研究核验通过。

源码仅用于讨论，选定布局后再以真实状态和服务契约实现；不直接把原型提为正式产品。待决策：哪个布局作为主入口、证据应默认打开到什么程度、窄屏如何在研究与成果之间切换。实现 issue 记录原型分支、验证与最终选择。

## 本轮观察与截图

2026-10-15 在实际浏览器验证：1440×1000 与 390×844 的三个布局均无横向溢出，输入和停止区保持可达；证据详情、模拟停止/继续、内存保存、T1 触发、T0 原值、缺板块与 T1 失效均已检查。输入框方向键不切换布局，浏览器未观察到脚本错误。官网静态构建通过且不含原型，production 环境启动会被拒绝。
